NIVEL 1 · ¿QUÉ ES UN AGENTE?

Un modelo + herramientas + un ciclo

MODELO
piensa y pide
→
HERRAMIENTA
leer · escribir · terminal
→
RESULTADO
regresa al modelo
↺

Se repite hasta que el modelo ya no pide nada. Eso es todo.

Claude Code, Cursor, Codex y pi son este ciclo con mejores herramientas y mejor contexto.

const mensajes = [{ role: "user", content: tarea }];
while (true) {
  const respuesta = await modelo(mensajes);
  mensajes.push(respuesta);
  mostrar(respuesta);

  const llamadas = herramientasPedidas(respuesta);
  if (llamadas.length === 0) break; // terminó

  const resultados = [];
  for (const llamada of llamadas) {
    const salida = ejecutar(llamada);
    resultados.push(resultado(llamada, salida));
  }
  mensajes.push({ role: "user", content: resultados });
}

NIVEL 2 · EL AGENTE SE HACE SUS HERRAMIENTAS

Le pides una función y se la escribe

En pi, una extensión es un archivo TypeScript: comandos, herramientas, barras de estado, candados de seguridad.

En vivo, le pido a pi:

"Crea una extensión de pi en ./costo.ts con
un comando /costo que muestre cuánto llevo
gastado en esta sesión y cuántos tokens."

Tarda unos 30 segundos. Luego abro pi con la extensión: pi -e ./costo.ts y escribo /costo.

// una extensión de pi (versión corta)
export default function (pi) {
  // un comando nuevo: /costo
  pi.registerCommand("costo", {
    description: "Lo gastado en la sesión",
    handler: async (args, ctx) =>
      ctx.ui.notify(`Gasto: $${gastado(ctx)}`),
  });

  // se ejecuta antes de cada herramienta
  pi.on("tool_call", async (evento) => {
    if (esPeligroso(evento))
      return { block: true, reason: "Eso no." };
  });
}

NIVEL 5 · EL CICLO DE PRODUCTO CORRE SOLO

Decide cuándo apagarlo antes de lanzarlo

Verdict (un agente) lanzó un anuncio en Meta de MX$700 para su app de preparación del ENARM.

Antes de gastar, escribió cuándo lo iba a apagar. 145 visitas → 2 personas empezaron. Lo apagó solo, siguiendo su propia regla, y le sobraron ~MX$495.

Sin esa regla, cualquier resultado "se ve prometedor".

NIVEL 5 · LEE LOS DATOS, NO EL DASHBOARD

72 % del gasto se iba en búsquedas de Huawei

Squatea (otro agente) lanzó una app de iOS con anuncios de Apple. El dashboard decía "impresiones subiendo".

El agente abrió los datos crudos: 72 % de las impresiones y 76 % del gasto se iban en búsquedas de Huawei y Xiaomi. Agregó 15 palabras negativas.

Vio a alguien negar el permiso de la cámara e irse. En la misma sesión construyó el botón "Abrir Ajustes".

LA PARTE HONESTA

Los agentes ejecutan. La demanda no se ejecuta.

14 agentes lanzando todos los días. Ingresos recurrentes de los productos autónomos: todavía menos de $1,000 dólares al mes. El código nunca fue el cuello de botella.

Afuera pasa lo mismo: un agente con presupuesto, producto y meta de $700 al mes generó $0 en un mes. El problema fue la demanda, no la ejecución.

Por eso producto es nuestro trabajo ahora: qué construir, para quién y cómo saber si funcionó.
